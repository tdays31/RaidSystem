# RaidSystem

텍스트 기반 레이드 게임. 외부 홈페이지에 삽입하는 것을 전제로 설계.

- 최종 갱신일: 2026-10-11

## 구조

```
src/
├─ index.html     # 레이아웃 (데모/삽입용 마크업)
├─ css/page.css   # 데모 페이지 전용 body 리셋 (삽입 시 제외)
├─ css/raid.css   # 스타일 (.rs-root 하위로 스코프 한정)
└─ js/raid.js     # UI 바인딩 (IIFE, 전역 오염 없음)
```

## 레이아웃

| 영역 | 위치 | 선택자 |
|---|---|---|
| 턴 수 / 레이드 보스 상태 | 좌측 상단 | `.rs-boss` |
| 채팅 출력 창 (시간 `HH:MM` · 이름 · 본문 정렬, 긴 본문은 본문 열 안에서 줄바꿈) | 좌측 중앙 | `.rs-chat-log` |
| 행동 버튼 + 행동 팝업 (공격/스킬/방어/회복) | 좌측 하단 | `.rs-action` |
| 채팅 입력 창 | 좌측 하단 | `.rs-chat-input` |
| 프로필 카드 (이름, 직업, 상태, HP, 공격/방어/치명) | 우측 상단 | `.rs-profile` |
| 파티원 상태창 (최대 5명, 이름/직업/상태/HP) | 우측 | `.rs-party` |

- 디자인: Parchment (판타지 RPG 양피지 톤, 세리프 제목)
- 화면 높이(100vh) 기준, 콘텐츠 최대 폭 1080px 중앙 정렬
- 좌측(메인) / 우측(사이드) 두 개의 카드(6px 라운드, 그림자), 간격 10px
- 열 비율 메인 2 : 사이드 0.86 (사이드 최소 252px)
- 영역 구분은 테두리 없이 배경색으로만 처리
- 채팅 출력 창은 남은 영역 고정 크기, 내용은 내부 스크롤
- HP는 바가 아닌 숫자(`현재 / 최대`)로 표시 (보스 제외)
- 768px 이하: 1열 배치 (사이드 영역 상단 이동, 채팅창 50vh 고정)

## 행동 팝업

`행동` 버튼(116px) 클릭 → 팝업(168px)에 `공격 / 스킬 / 방어 / 회복` 한 줄씩 표시.
항목을 눌러도 바로 송출되지 않고, **선택 → 하단 요약 확인 → `확인` 클릭** 시 송출.

| 행동 | 다음 단계 | 채팅 메시지 (확인 후) |
|---|---|---|
| 공격 | 바로 선택됨 | `플레이어가 공격을 선택했습니다.` |
| 스킬 › | 보유 스킬 3개 중 선택 | `플레이어가 스킬 강타를 선택했습니다.` |
| 방어 › | 대상 선택 (자신 + 파티원) | `플레이어가 도윤을 대상으로 방어를 선택했습니다.` |
| 회복 › | 대상 선택 (자신 + 파티원) | `플레이어가 자신을 대상으로 회복을 선택했습니다.` |

- 선택한 항목은 진한 녹색으로 표시, 하단에 요약(예: `방어 · 도윤`) 표시
- 선택 전 `확인` 버튼 비활성, 확인 전까지 다른 항목으로 자유롭게 변경 가능
- 하위 단계: 상단 `← 뒤로` 버튼으로 행동 목록 복귀
- 취소: 바깥 클릭, 행동 버튼 재클릭 (선택 내용 초기화). `Esc`는 하위 단계에서 뒤로, 첫 단계에서 닫기
- 키보드: `↑ / ↓` 이동, `Enter` 선택, 선택 후 `확인` 버튼으로 포커스 이동
- 조사(이/가, 을/를)는 `josa()`로 자동 처리
- 구성
  - `ACTIONS`: 행동 정의 (`next`: `null` 즉시 선택 / `'skill'` / `'target'`)
  - `state.player.skills`: 보유 스킬 (데모: 강타, 전투의 함성, 회오리 베기)
  - `setSelection()`: 선택 상태 저장 / `submitAction()`: 송출 지점 (추후 서버 전송)
- 팝업 항목은 현재 단계 배열의 인덱스로만 처리 (DOM 값 직접 신뢰 안 함)

## 직업군

직업은 **고정** (게임 중 변경 불가). 정의: `raid.js`의 `JOBS`.

| 직업 | 회복 | 방어 대상 |
|---|---|---|
| 힐러 (`healer`) | 가능 (자신 + 파티원) | 자신만 |
| 딜러 (`dealer`) | 행동 목록에서 숨김 | 자신만 |
| 탱커 (`tank`) | 행동 목록에서 숨김 | 자신 + 파티원 |

- 회복 노출: `isActionAvailable()` / 대상 목록: `getTargets()`
- 방어 대상이 자신뿐이면 대상 단계 없이 바로 `방어 · 자신` 선택
- 데모: 플레이어 탱커, 아린 딜러, 도윤 탱커, 세라 힐러, 카이 딜러

## 행동완료 표시

- 이름 앞 마름모: 대기 `◇`(보조 텍스트색) / 완료 `◆`(메인 녹색) — 채팅 시스템 메시지 장식과 통일
- 데이터: `state.player.done`, `state.party[].done` → 컨테이너 `data-done="true|false"` (`applyDone()`)
- 스크린리더/툴팁: `행동 완료` / `행동 대기`
- 행동 `확인` 송출 시 플레이어 `done = true`
- 데모: 아린·세라 완료, 도윤·카이 대기

## 삽입 / 보안 원칙

- 삽입 시 `#raid-system` 블록 + `raid.css` + `raid.js`만 사용
- 모든 CSS 클래스 `rs-` 접두사, `.rs-root` 하위 스코프 → 호스트 페이지와 충돌 방지
- 인라인 스크립트/스타일 미사용 → CSP 적용 가능
- DOM 출력은 `textContent`만 사용 (`innerHTML` 금지) → XSS 방지
- 채팅 입력: 제어문자 제거, 200자 제한, 로그 최대 200개 유지
- 파티원 렌더링 시 최대 5명으로 제한 (`MAX_PARTY_SIZE`)
- DOM 접근은 `data-rs` 속성 기반 → 스타일 변경과 로직 분리
