# RaidSystem

텍스트 기반 레이드 게임. 외부 홈페이지에 삽입하는 것을 전제로 설계.

- 최종 갱신일: 2026-10-11

## 구조

```
src/
├─ index.html     # 레이아웃 (데모/삽입용 마크업)
├─ css/raid.css   # 스타일 (.rs-root 하위로 스코프 한정)
└─ js/raid.js     # UI 바인딩 (IIFE, 전역 오염 없음)
```

## 레이아웃

| 영역 | 위치 | 선택자 |
|---|---|---|
| 턴 수 / 레이드 보스 상태 | 좌측 상단 | `.rs-boss` |
| 채팅 출력 창 | 좌측 중앙 | `.rs-chat-log` |
| 행동 선택 | 좌측 하단 | `.rs-action` |
| 채팅 입력 창 | 좌측 하단 | `.rs-chat-input` |
| 프로필 카드 (이름, 현재 상태) | 우측 상단 | `.rs-profile` |
| 파티원 상태창 | 우측 | `.rs-party` |

- 768px 이하: 1열 배치 (사이드 영역이 상단으로 이동)

## 색상

| 용도 | 값 |
|---|---|
| 메인 (녹색) | `#1e6b3a` / `#2e9e55` / `#123d24` |
| 보조 (노랑) | `#f5c518` / `#fff7d1` |
| 보조 (흰색) | `#ffffff` |
| 본문 텍스트 | `#1b1f1c` (흰 배경), `#ffffff` (녹색 배경) |

색상은 `.rs-root`의 CSS 변수(`--rs-*`)로 관리.

## 삽입 / 보안 원칙

- 삽입 시 `#raid-system` 블록 + `raid.css` + `raid.js`만 사용
- 모든 CSS 클래스 `rs-` 접두사, `.rs-root` 하위 스코프 → 호스트 페이지와 충돌 방지
- 인라인 스크립트/스타일 미사용 → CSP 적용 가능
- DOM 출력은 `textContent`만 사용 (`innerHTML` 금지) → XSS 방지
- 채팅 입력: 제어문자 제거, 200자 제한, 로그 최대 200개 유지
- DOM 접근은 `data-rs` 속성 기반 → 스타일 변경과 로직 분리
